How it works

Three steps to agents you can trust.

The model proposes. Aegis decides, outside the model, so it cannot be talked past.

  1. 01

    Connect your agent

    Point Claude, Cursor or your own agent at Aegis, or build one in the Studio with any model. Two minutes, no code changes.

  2. 02

    Decide what it may do

    Give each agent only the abilities it needs. Your rules say what runs on its own, what asks you first, and what never runs.

  3. 03

    Stay in control

    Approve risky actions in one click, see every step it took, and download a report or a signed receipt anyone can check.

Connect Claude Code in one line

claude mcp add --transport http aegis \
  "https://<your-aegis>/mcp?agent=<agent id>" \
  --header "Authorization: Bearer <key>"

Questions

The usual doubts, answered.

Is it really free?

Yes. Every feature on this page is in the free plan, with no seat limits, no trial and no card. You run it on your own machine today; a hosted version is on the way.

What is MCP, and do I need it?

MCP is the open standard most agents use to reach tools. If your agent speaks MCP (Claude Desktop, Cursor, Claude Code and many others), you connect it to Aegis with one line. If not, build the agent in the Studio and Aegis runs it for you.

Does Aegis see my data or keys?

It runs where you run it. Model keys and mail passwords are stored encrypted and never shown again. Nothing is sent to us.

Which models work?

Local models through Ollama, OpenAI, Anthropic, and any OpenAI-compatible service such as Groq, Together or vLLM.

What happens when an agent tries something risky?

It waits. You see exactly what it wants to do, with the real details, and approve or reject it. If you approve, that exact action runs once; if anything changes, it asks again.

Can I prove what an agent did?

Every step is hash-chained and signed. Export any task as a receipt and verify it offline, without trusting Aegis.
