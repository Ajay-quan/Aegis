How it works

Set up in three steps

  1. Step 1

    Connect the agent you already use

    Pick which agent it acts as, create a key, and paste the config into Claude Desktop, Cursor or Claude Code. Or build an agent in the Studio with any model.

  2. Step 2

    Give it only what it needs

    List the abilities each agent has. For every one you can see what will happen when it tries: it runs on its own, it asks you first, or it is blocked.

  3. Step 3

    Say yes or no to the risky parts

    When an agent wants to do something your rules hold back, you see the exact email, export or request it wants to send, and approve it once or reject it.

MCP gateway

Connect an agent with one command.

Your agent talks to Aegis instead of straight to its tools. Each call goes through the checks below, and only the ones that pass reach the tool.

  1. Your agentClaude Desktop, Cursor, your own code
  2. Who is asking
  3. What it may use
  4. What it already touched
  5. How risky
  6. Your rules
  7. A person, if needed
  8. Your toolsonly allowed calls arrive
Allowed
Runs straight away, and is recorded.
Held
Waits for you. If you approve, that exact call runs once.
Blocked
Never reaches the tool.

For Claude Code

claude mcp add --transport http aegis \
  "https://<your-aegis>/mcp?agent=<agent id>" \
  --header "Authorization: Bearer <key>"

The Studio fills in the address and key, and has the same for Claude Desktop and Cursor.

Questions

Common questions

Is it really free?

Yes. Everything on this page is free, with no seat limits, no trial and no card. Today you run it on your own machine; a hosted version is coming.

What is MCP, and do I need it?

MCP is the open standard most agents use to reach tools. If your agent speaks it (Claude Desktop, Cursor, Claude Code and many others), you connect it to Aegis with one line. If it doesn't, build the agent in the Studio and Aegis runs it for you.

Does Aegis see my data or keys?

It runs wherever you run it. Model keys and mail passwords are stored encrypted and never shown again. Nothing is sent to us.

Which models work?

Local models through Ollama, OpenAI, Anthropic, and any OpenAI-compatible service such as Groq, Together or vLLM.

What happens when an agent tries something risky?

It waits. You see what it wants to do, with the real details, and approve or reject it. If you approve, that exact action runs once; if anything about it changes, it asks again.

Can I prove what an agent did?

Yes. Every step is hash-chained and signed, and any task can be exported as a receipt that checks out offline.

Try it on your own machine.

You need Docker. It takes about five minutes, and free local models through Ollama work out of the box.

A hosted version is on the way. Watch the repository to hear when it opens.
