What a harness is

Everything around the model that makes its work safe to trust. It remembers, it decides, it records, and it lets a person step in. The model proposes. The harness disposes.

01AegisMem

Memory that lasts, and stays correct.

Persistent memory for agents, found by meaning and by keyword. Contradictions are caught, and every fact can be traced, corrected and erased.

  • Hybrid semantic and keyword retrievalBuilt
  • Contradiction detection and reviewBuilt
  • Recall ranking that learns from what agents useBuilt
  • Knowledge-graph relationshipsIn progress

02AegisTrace

Every step an agent takes, on the record.

One trace per run, across every model and tool call. Each step is signed, so the record can be verified offline.

  • End-to-end traces across servicesBuilt
  • Signed, verifiable execution recordsBuilt
  • Token usage and estimated costBuilt

03AegisRuntime

Runs that finish, even when things fail.

Agents run on a durable state machine. When a worker crashes or a dependency restarts, another worker picks the run up.

  • Durable orchestration with leasesBuilt
  • Recovery from crashes and outagesBuilt
  • Multi-agent workflow definitionsPlanned

04AegisGuard

Nothing runs until you allow it.

Default-deny permissions enforced outside the model. Risky actions wait for a person, and each organization is sealed off from every other.

  • Policy enforcement and human approvalBuilt
  • Roles, API keys and an audit logBuilt
  • Encryption at rest and erasureBuilt

05AegisEval

Know an agent is better before it ships.

Test suites, benchmarks and regression checks that show whether a change helped, and where it failed.

  • Memory retrieval benchmarksBuilt
  • Agent test suites and regression checksBuilt
  • Version-to-version comparisonsBuilt

06AegisOptimize

The same answer, for fewer tokens.

Compress context, cache what repeats and route each task to the smallest model that does it well.

  • Token and cost reportingBuilt
  • Findings and savings experimentsBuilt
  • Context compression and cachingPlanned

07AegisModels

Any model, hosted or local.

Register hosted APIs and local models in one hub, test the connection, and run agents on them. Keys are stored encrypted.

  • Hosted and local models (OpenAI-compatible, Ollama)Built
  • Connection tests and encrypted keysBuilt
  • Fine-tuning with LoRA and QLoRAPlanned

08AegisStudio

One place to build, watch and govern.

The workspace where developers build agents, inspect runs, review approvals, explore memory and manage the platform.

  • Agents, runs, approvals, memory and securityBuilt
  • Sign-in, members, roles and API keysBuilt
  • Evaluation, optimization and deploymentsBuilt
