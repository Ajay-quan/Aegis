# Security policy

AegisTrace is pre-release software. **It has not had an independent security review.** Do not use it to protect production systems or to run untrusted customer code.

Report vulnerabilities privately to the maintainers; do not open a public issue. A dedicated disclosure address and PGP key will be published before the first release.

The security design is documented in `docs/aegistrace/security/`. Known gaps are in `docs/aegistrace/product/OPEN_ISSUES.md`.
