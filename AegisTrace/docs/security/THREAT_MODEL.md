# Threat model

Method: STRIDE per trust boundary (see TRUST_BOUNDARIES.md). The categories follow OWASP Top 10 for LLM Applications and agentic-AI guidance, the OWASP ASVS, and MITRE ATLAS/ATT&CK concepts. Every row names the automated test that exercises the control.

**Residual risk is real. No independent security review has been performed (§48).**
